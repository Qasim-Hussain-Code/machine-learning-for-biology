# Machine Learning for Biology

A book in seven chapters, written from the daily series Machine Learning for Biology (24 July to 1 October 2026).
Each chapter asks one biological question with one model, from logistic regression to k-means, and fixes its rules
before running anything.

The book is being prepared. The code for each chapter stays in its own repository; `companions.yml` lists them and
pins each to the commit the chapter describes.
